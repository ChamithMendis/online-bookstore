💡 Purpose:
Holds reusable UI components, pipes, and directives that can be used in multiple places.

Inside:

components/

navbar/ → navbar.component.ts
Top navigation bar, likely shown in the main layout after login.

sidebar/ → sidebar.component.ts
Sidebar menu with navigation links (e.g., Add Items, View Books).

pipes/
Custom Angular pipes for formatting data (e.g., date formatting, text truncation).

directives/
Reusable custom directives (e.g., auto-focus on input fields).
