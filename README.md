# ☁️ Online Bookstore using Angular + Spring Boot + MYSQL + AWS

This full-stack bookstore app uses AWS EC2, RDS, and S3 for hosting, database, and file storage. It demonstrates deployment and configuration of a production-ready cloud-native system.

🚀 Hosting Architecture on AWS

- Angular frontend hosted on AWS S3
- Spring Boot backend deployed on EC2
- MySql hosted on RDS
